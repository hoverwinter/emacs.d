* Key Bindings

** Navigation (Avy)

| Key         | Command          | Description                          |
|-------------+------------------+--------------------------------------|
| =C-c SPC=   | avy-goto-char    | Jump to a character anywhere visible |
| =M-g l=     | avy-goto-line    | Jump to a visible line               |

** File Tree (Neotree)

| Key   | Command          | Description          |
|-------+------------------+----------------------|
| =F8=  | neotree-toggle   | Toggle file sidebar  |

** Search & Completion (Consult)

| Key       | Command            | Description                |
|-----------+--------------------+----------------------------|
| =C-s=    | consult-line       | Search lines in buffer     |
| =C-x b=  | consult-buffer     | Switch buffer              |
| =M-g g=  | consult-goto-line  | Go to line number          |
| =M-s r=  | consult-ripgrep    | Ripgrep project search     |

** Org-mode

| Key       | Command          | Description             |
|-----------+------------------+-------------------------|
| =C-c l=  | org-store-link   | Store an org link       |
| =C-c a=  | org-agenda       | Open agenda             |
| =C-c c=  | org-capture      | Capture a note          |

** Snippets (YASnippet)

| Key       | Command     | Description        |
|-----------+-------------+--------------------|
| =C-c k=  | yas-expand  | Expand snippet     |

** Formatting (clang-format)

| Key         | Command              | Description               |
|-------------+----------------------+---------------------------|
| =C-c C-f=  | clang-format-region  | Format selected region    |
