* Yet Another Emacs Configuration

Requires *Emacs 29+*.

** Features

- *use-package* (built-in) for declarative package management
- *Vertico / Orderless / Marginalia / Consult* for minibuffer completion
- *Corfu / Cape* for in-buffer completion
- *Eglot* (built-in) for LSP (clangd for C/C++)
- *treesit-auto* for Tree-sitter syntax highlighting
- *Avy* for jump-to-visible-text navigation
- *Magit* for Git
- *YASnippet* for snippets
- *clang-format* for C/C++ formatting
- *Neotree* for file tree sidebar
- *Org-mode* with capture / agenda

** Structure

| File               | Purpose                              |
|--------------------+--------------------------------------|
| =early-init.el=    | GC tuning for fast startup           |
| =init.el=          | Load path & require modules          |
| =init.d/=          | One file per feature                 |

** About this document

Written in Emacs /org-mode/. GitHub renders =*.org= natively.
